# TradingAgents-CN 个股分析系统说明文档

## 一、系统概述

TradingAgents-CN 是一个基于多 Agent 协作的智能股票分析系统，通过多个专业分析师的分工协作，实现对股票的全面分析。系统采用多轮辩论机制，综合市场技术分析、情绪分析、新闻分析、基本面分析等多个维度，最终给出投资建议。

---

## 三、Agent 角色详解

| Agent | 角色 | 模型 | 主要任务 |
|-------|------|------|---------|
| **Market Analyst** | 市场分析师 | quick_thinking_llm | 技术分析、K线形态、支撑阻力位 |
| **Social Media Analyst** | 社交分析师 | quick_thinking_llm | 雪球/东财股吧情绪分析 |
| **News Analyst** | 新闻分析师 | quick_thinking_llm | 财经新闻摘要与影响评估 |
| **Fundamentals Analyst** | 基本面分析师 | quick_thinking_llm | 财务数据、估值指标、目标价位 |
| **Bull Researcher** | 看涨研究员 | quick_thinking_llm | 构建看涨论点，反驳看跌观点 |
| **Bear Researcher** | 看跌研究员 | quick_thinking_llm | 构建看跌论点，反驳看涨观点 |
| **Research Manager** | 研究经理 | **deep_thinking_llm** | 综合辩论结果，给出投资建议 |
| **Trader** | 交易员 | quick_thinking_llm | 制定具体交易计划 |
| **Risk Analysts** | 风险分析师组 | quick_thinking_llm | 多角度风险辩论 |

## 十、注意事项

1. **PE_TTM 优先原则**: 系统优先使用 Tushare 的 PE_TTM（基于过去12个月净利润）而非静态 PE（基于单季度每股收益），以获得更准确的估值水平。

2. **货币单位约束**: 各 Agent 的提示词中明确指定了股票所属市场的货币单位（中国A股用人民币¥，美股/港股用美元$）。

3. **中文输出要求**: 所有分析内容、投资建议必须使用中文（买入/持有/卖出），禁止使用英文（buy/hold/sell）。

4. **数据真实性约束**: 强制要求各分析师调用工具获取真实数据，禁止假设或编造数据。

5. **目标价位强制要求**: 交易员和研究经理必须提供具体的目标价位，禁止回复"无法确定"或"需要更多信息"。
